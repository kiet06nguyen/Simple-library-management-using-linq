# LinqConsoleExampleJSON
A simple C# project that demonstrates how to use LINQ and JSON to create a book lending library.

## Introduction
This project demonstrates how to use LINQ (Language Integrated Query) and JSON to output to the screen in C#. The project includes examples of querying a list, filtering data, sorting and grouping data in a console application, and converting to JSON.

## How to run
Requirements:

`.NET SDK (minimum .NET 6.0 or your preferred version)`

`An IDE like Visual Studio or VS Code (recommended)`
